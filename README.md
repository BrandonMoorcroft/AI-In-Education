# Ai-In-Education
A python program that can be used to create a dashboard and also host a set of important data; pertaining to the use of AI in schools at the university level. 

## Final Project - Github Repository
Group 6 has chosen to work on creating a collection of data for the AI levels and such for students in university. The data used is from aprox. July 2026.

The task is to maintain and use a variety of tools learned throughout workshop sessions to create an effective dashboard, a set of visualizations and to understand data cleaning/wrangling. 
The end result will also include a report which can be found here on github as well.
The repository is expected to be edited by 8 people, either in branches or on the main branch. With commits and pulls occurring between the different platforms.
